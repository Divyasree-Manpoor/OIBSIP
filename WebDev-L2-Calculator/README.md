# Calculator Web Application

A responsive browser-based calculator built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Numbers from 0 to 9
- Decimal number support
- Clear button
- Delete button
- Division-by-zero error handling
- Operator chaining
- Keyboard support
- Responsive design
- CSS Grid-based calculator layout
- Input handling using JavaScript event listeners

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
