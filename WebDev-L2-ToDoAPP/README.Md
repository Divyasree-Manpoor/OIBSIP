# Task Management Application

A responsive and interactive task management web application designed to help users organize, track, and manage everyday tasks efficiently.

## Features

- Add new tasks
- Mark tasks as completed
- Mark completed tasks as pending
- Edit existing tasks
- Delete tasks
- Filter tasks by:
  - All
  - Pending
  - Completed
- Display total, pending, and completed task counts
- Persistent task storage using browser Local Storage
- Dynamic empty-state messages
- Keyboard support while editing tasks
- Responsive design for desktop, tablet, and mobile devices
- Input validation to prevent empty tasks

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API
