# Login Authentication System

A responsive frontend authentication system built with HTML5, CSS3, and JavaScript.

The application demonstrates user registration, password validation, password hashing, login authentication, protected dashboard access, session handling, and logout functionality.

---

## Features

- User registration
- Username/email validation
- Password validation
- Password confirmation
- Duplicate account detection
- SHA-256 password hashing
- Secure password comparison
- User login
- Generic invalid-credentials message
- Protected dashboard
- Active session handling
- Logout functionality
- Responsive user interface
- Browser-based data persistence using Local Storage
