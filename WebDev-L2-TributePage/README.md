# Tribute Page — Dr. A. P. J. Abdul Kalam

A responsive tribute webpage dedicated to Dr. A. P. J. Abdul Kalam, highlighting his life, scientific contributions, achievements, and lasting legacy.

## Features

- Responsive design for desktop, tablet, and mobile
- Hero section with title and tagline
- Navigation with smooth scrolling
- Prominent tribute image
- Biography section
- Major milestones timeline
- Legacy and achievements section
- Inspirational quote section
- Responsive image layout
- Hover effects and interactive navigation

## Technologies Used

- HTML5
- CSS3
- Google Fonts
